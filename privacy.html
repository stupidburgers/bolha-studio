Privacy Policy

Bolha Studio is a private tool used only by its owner to upload and manage videos and read analytics on the owner's own YouTube channels through the YouTube API Services.

It collects no data from other people. OAuth tokens are stored only on the owner's own machine and are never shared or sold. Data obtained from the YouTube API is used only to manage the owner's channels.

Bolha Studio uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. You can revoke access at Google security settings.
